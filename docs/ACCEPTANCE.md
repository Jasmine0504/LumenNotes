# 验收清单（iOS 26 / Mac）

> 前提：Xcode 26、iOS 26 模拟器或真机、`xcodegen generate` 成功、`xcodebuild` 零错误。  
> 当前 Windows 环境无法执行本清单；这是给 Mac 的交接单。

## 0. 启动

- [ ] `xcodebuild build -scheme LumenNotes -destination 'generic/platform=iOS'` 通过
- [ ] `xcodebuild test -scheme LumenNotes -destination 'platform=iOS Simulator,name=iPhone 17'` 通过
- [ ] App 冷启动进入“流明”列表，无崩溃
- [ ] 示例数据出现：欢迎、本周要做、玻璃与纸、正在读
- [ ] 系统深色模式切换正常，正文对比度足够

## 1. 基础备忘录

- [ ] 点“新建备忘录”，进入编辑器，标题/正文分离
- [ ] 输入标题与正文，返回列表，标题/摘要/时间出现
- [ ] 长按列表行 → 移动到文件夹 → 选择“工作/生活/灵感/阅读”
- [ ] 长按列表行 → 删除 → 确认，行消失
- [ ] 强杀 App 重开，新建内容仍在
- [ ] 文件夹按钮 → 新建子文件夹、重命名、删除；子项不被误删

## 2. 核对清单 / 富文本 / 折叠

- [ ] 工具栏 `textformat` → H1/H2/H3，字号层级明显
- [ ] 工具栏 B/I/高亮，选中文本后生效
- [ ] 段落样式：正文、项目符号、编号、引用、高亮段落
- [ ] 核对清单勾选后圆点变实心、文本删除线
- [ ] 核对清单增删项目
- [ ] 标题左侧 V 箭头折叠/展开；折叠后隐藏直到下一个同级标题
- [ ] 换字体/字号后，粗体/斜体/高亮仍在

## 3. 附件

- [ ] `+` → 照片，选图，正文出现缩略图
- [ ] 点缩略图 → 全屏预览
- [ ] 文件 App 选 PDF → PDF 内联卡片 → 预览
- [ ] PDF 右上角“标注”→ 手写一笔 → 完成 → 重开仍在
- [ ] `+` → 链接 → 输入 https URL → 富卡片 → 点击打开
- [ ] `+` → 地点 → 输入名称/经纬度 → 地图卡片 → 预览
- [ ] 附件卡片删除后，正文块消失

## 4. 录音 / 转写

- [ ] 麦克风按钮 → 授权 → 波形出现
- [ ] 说“今天下午三点开会”，正文出现时间标记 + 文字
- [ ] 暂停 2 秒，继续，文本不丢、不重复整段
- [ ] 停止后出现音频附件，预览可播放
- [ ] 录音文字可被搜索命中
- [ ] 无 SpeechAnalyzer 资产时，回退 SFSpeechRecognizer（真机）

## 5. 文档扫描

- [ ] `+` → 扫描 → 相机 → 拍一页 → 保存
- [ ] 生成 PDF 附件，内联卡片显示“扫描文稿 · 1 页”
- [ ] 搜索 OCR 中的词可命中该备忘录
- [ ] 模拟器无相机时 → 照片 → Vision OCR → PDF 回退
- [ ] 多页扫描生成多页 PDF

## 6. 表格 / 速绘

- [ ] `+` → 表格，编辑单元格
- [ ] 增加行/列，删除末行/末列
- [ ] `+` → 速绘，切换空白/网格/横线
- [ ] 选笔刷、颜色、橡皮，画一笔
- [ ] 完成 → 缩略图；重开 App 仍在
- [ ] 速绘上的手写字可用搜索命中（Vision OCR）

## 7. 整理 / 搜索 / 智能文件夹 / 内链

- [ ] 正文输入 `#设计`，列表出现“#设计”标签
- [ ] 点标签过滤，只显示含该标签的笔记
- [ ] 搜索“设计”“核对”“扫描 OCR 词”“手写词”均能命中
- [ ] 新建智能文件夹“含核对清单且本周创建”，只显示符合项
- [ ] 条件构建器实时显示匹配数与 predicate 字符串
- [ ] 正文输入 `>>`，弹出备忘录选择器
- [ ] 选一条，插入内部链接卡片，点击跳转
- [ ] 嵌套文件夹筛选包含子文件夹笔记

## 8. 锁定

- [ ] 编辑器右上角锁 → 列表只显示锁图标，摘要隐藏
- [ ] 强杀重开 → 打开该笔记，自动弹 Face ID/设备密码
- [ ] 认证成功，正文恢复
- [ ] 解锁后切后台 → 立即重锁
- [ ] 设置 30 秒 → 解锁后等待 30 秒 → 自动重锁
- [ ] 设置“不自动” → 解锁后不自动锁，但切后台仍立即锁
- [ ] 加密后 SwiftData 的 `contentData` 为空（可在调试器/导出中验证）
- [ ] 错误的 Face ID 取消后，显示错误，不泄露正文

## 9. 快速备忘录 / 系统集成

- [ ] 控制中心添加“新建备忘录”，点击打开并创建
- [ ] Siri/快捷指令“用流明笔记新建备忘录”
- [ ] iPad 硬件键盘 Fn-Q 创建
- [ ] 桌面长按 App 图标“新建备忘录”
- [ ] `lumen://new` 打开新笔记
- [ ] `lumen://note/<uuid>` 打开指定笔记
- [ ] 编辑笔记时，系统 Spotlight/Handoff 的 NSUserActivity 有标题与 URL

## 10. 字体 / 字号（核心）

- [ ] 设置页六种字体，每项以自身字形显示“备忘录 Aa 123”
- [ ] 标题/正文/辅助三档分别 12–32pt，滑块步长 1
- [ ] A-/A+ 与滑块同步，边界 12/32 禁用
- [ ] 设 Georgia 22pt → 返回任意笔记 → 正文立即变
- [ ] 开 Dynamic Type，系统设置放大 → 文本随之放大
- [ ] 关 Dynamic Type，系统放大 → 文本严格保持手动字号
- [ ] “仅此备忘录”开启 → 只影响当前笔记
- [ ] 关闭“仅此备忘录” → 回退全局
- [ ] 换字体后已有粗体/斜体/高亮保留
- [ ] 重启 App 后字体设置保留

## 11. Liquid Glass

- [ ] 编辑器工具栏有玻璃质感，相邻按钮融合
- [ ] 点 `+` 展开插入面板，有形变/过渡
- [ ] 列表行无玻璃
- [ ] 正文区域无玻璃，是实色/渐变纸张
- [ ] 附件卡片无玻璃
- [ ] 表格单元格无玻璃
- [ ] 标签 Chip 无玻璃
- [ ] 智能文件夹卡片无玻璃
- [ ] 搜索栏、FAB、录音面板、字体面板是玻璃
- [ ] 增强对比度开启 → 玻璃控件回退不透明
- [ ] 在 iOS 26 以下（若改部署目标）回退材质布局不崩溃、可点击

## 12. 回归 / 性能

- [ ] 新建 100 条笔记，列表滚动不卡顿（内存搜索可接受）
- [ ] 10 页扫描 PDF 插入后，App 不崩
- [ ] 5 分钟录音，内存不持续暴涨
- [ ] 锁定的笔记不出现在 Spotlight 摘要中
- [ ] 删除笔记后，附件与标签关系不残留（SwiftData cascade/nullify）
